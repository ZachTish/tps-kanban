# TPS Kanban 0.0.1

## Release intent

This is the initial private GitHub release package for installing and updating the existing TPS Kanban `0.0.1` build with BRAT. Packaging it for BRAT does not change runtime behavior. The release must attach the already-tested `main.js`, `manifest.json`, and `styles.css` artifacts.

## Compatibility

- Minimum Obsidian version: `1.10.0`, recorded in both `manifest.json` and `versions.json`.
- Mobile-compatible according to `manifest.json`; Kanban depends on Obsidian's Bases APIs.
- Private-repository BRAT installs require a fine-grained GitHub token scoped to `ZachTish/tps-kanban` with **Contents: Read-only**; the token must never be committed.

## Validation

- `npm test`: passed `51/51` tests across shared TPS contracts, Base-filter composition, and Kanban behavior utilities.
- Separate `npm run build`: passed TypeScript checking and the production esbuild bundle.
- Test-vault deployment: `[runtime-deploy] target=test ... unchanged`; all three runtime artifacts are byte-identical to the built source artifacts.
- No production deployment or reload was performed. This package remains test-vault-only until an explicitly authorized promotion.

## Known limitations

- The `tps list` Bases view is owned and distributed by TPS Global Context Menu, not by this plugin.
- Native physical drag/drop remains a manual UI verification point even though task-line mutation and drop-decision behavior are covered by tests.
- Because the repository is private, each BRAT installation must retain valid read-only GitHub authentication on that device.
