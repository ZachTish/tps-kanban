# TPS Kanban 0.0.2

This patch prevents stale settings writes and repairs two normalization paths.

## Changes

- Reloads current plugin data and applies only locally changed settings, preserving synchronized and unknown fields.
- Retains overlapping change/revert intent and waits for durable persistence.
- Preserves an intentionally empty card-style rule list and every supported frontmatter color target.

## Compatibility and validation

- Minimum Obsidian: 1.10.0; desktop and mobile supported; no manual migration.
- Focused persistence/normalization tests and full declared suite: 57/57 passed; TypeScript and diff checks passed.
- A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; Kanban registered normally and no runtime settings file was created or replaced.
- Physical drag/drop remains a manual UI verification point.
