# TPS Kanban 0.1.4

TPS Kanban `0.1.4` is a backward-compatible frontmatter reliability patch. It makes the three GCM-sensitive tag and parent-link writes use TPS Global Context Menu's supported service directly instead of depending on a global Obsidian method interception.

## Changes

- Tag-lane card moves call `services.frontmatter.process` when TPS Global Context Menu exposes it.
- Card-nesting parent removal and parent assignment use the same supported route.
- Native Obsidian `fileManager.processFrontMatter` remains available only when the GCM frontmatter service is unavailable, preserving standalone Kanban use.
- A GCM `false` result or rejection is returned to the caller without retrying natively. Each action therefore has one mutation attempt and cannot bypass a GCM refusal.
- The existing status service route, generic property `setValues` route, native generic-property fallback, tag merge behavior, parent-key selection, link formatting, refresh events, settings, commands, and stored data contracts are unchanged.

## Before/after evidence

Released `0.1.3` invoked Obsidian's global `fileManager.processFrontMatter` directly for these three writes. When GCM was enabled, they received GCM serialization, validation, normalization, activity, index, event, and auto-rename behavior only because GCM intercepted the host method globally. Removing that interception would silently change the route.

In `0.1.4`, the three callsites share one small explicit router:

- With GCM available, one service call is made and native Obsidian is not called.
- Without GCM, one native call is made.
- A service return of `false` produces no native retry.
- A service error is propagated unchanged and produces no native retry.

This preserves current behavior while removing the three callsites' dependency on unsupported global interception.

## Compatibility and limitations

- Minimum supported Obsidian version remains `1.10.0`.
- No settings or data migration is required.
- TPS Global Context Menu remains optional. Standalone Kanban installations continue to use Obsidian's native Markdown frontmatter API.
- A GCM refusal remains a failed mutation; Kanban deliberately does not bypass it with a native retry.
- This patch does not change the existing generic property-routing hierarchy.
