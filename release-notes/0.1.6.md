# TPS Kanban 0.1.6

TPS Kanban `0.1.6` is a backward-compatible card-style evaluation performance patch. It removes eager suffix evaluation and temporary boolean arrays while preserving the complete released feature set.

## Changes

- Note-card and task-card style rules now use native short-circuit evaluation.
- An `any` rule stops after its first true condition; an `all` rule stops after its first false condition.
- Rule order and exact first-matching-rule identity remain unchanged.
- Inactive rules, empty or non-array condition lists, and the existing undefined/unsupported-match-as-`all` behavior remain unchanged.
- All condition operators and note frontmatter, task frontmatter, task inline-field, checkbox-status, and task-kind data paths remain unchanged.
- No command, setting, schema, integration contract, creation flow, drag/drop behavior, or persisted data changed.

## Before/after evidence

The release comparator compiles and executes the real private style-rule resolvers from exact public `0.1.5` and the candidate. The baseline source is SHA-256 pinned to `f0b12dc6254ad39e5ebed94e4cd15ed5b3d969f83de63558aebdc2e6346dcf3c`.

- 200,000 deterministic randomized cases alternated between the real note and task resolvers, covered every supported operator, and produced zero selected-rule identity/null differences.
- The parity digest was `b2501a758c6fbcc2d6c6d1af34db2721d4bc7edba6a19577e1eea05792af7f64`.
- Randomized condition evaluations fell from `1,141,701` to `444,027`; 134,626 cases performed less work and no case performed more.
- A decisive 30,000-card, 12-rule × 8-condition workload fell exactly from `2,880,000` evaluations to `360,000` (87.5%).
- Worst-case `any` and `all` paths still evaluate all eight conditions in both note and task resolvers.
- In the 6,000-card mixed stress benchmark, 15-sample median time fell from `12.87 ms` to `2.53 ms` and p95 from `13.32 ms` to `2.74 ms`.
- In the five-rule × one-condition guard benchmark, evaluation counts remained exactly equal at `2,250,000`; 15-sample median time improved from `11.83 ms` to `10.79 ms` and p95 from `12.09 ms` to `11.23 ms`.
- The production bundle decreased from `228,729` to `228,691` bytes while preserving identical stylesheet output.

The comparator hard-fails on a baseline source mismatch, selected-rule identity difference, candidate evaluation increase, operation-count mismatch, multi-condition median above 50% or p95 above 60% of baseline, or one-condition median/p95 regression above 5%.

## Compatibility and limitations

- Minimum supported Obsidian version remains `1.10.0`.
- No settings or data migration is required.
- No released feature or fallback path was removed in this patch.
- Style-rule evaluation remains synchronous and in configured order. Short-circuiting intentionally skips suffix conditions once they cannot affect the rule result.
- The whole-vault Base-note recovery path is intentionally unchanged because it can recover matching cards absent from native groups; removing it without a replacement contract could hide released content.
