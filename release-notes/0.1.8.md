# TPS Kanban 0.1.8

TPS Kanban `0.1.8` is a backward-compatible note-tag filtering performance and reliability patch. It reads one supported Obsidian metadata-cache snapshot per note and reuses that snapshot for both frontmatter and inline tags.

## Changes

- Replace two consecutive `getFileCache()` calls in fallback note-tag comparison with one invocation-local snapshot.
- Preserve frontmatter-first ordering, inline-tag ordering, tag normalization, duplicate removal, and exact filter output.
- Prevent one synchronous comparison from combining frontmatter and inline tags from different metadata snapshots.
- Add focused actual-method regression coverage for combined, normalized, deduplicated tag output and the one-read budget.
- Add no cache, state, fallback, retry, monkeypatch, listener, timer, setting, persisted field, migration, or unsupported API.

## Before/after evidence

- Exact public `0.1.7` and candidate actual methods matched across 100,000 seeded stable-cache cases with zero output or error mismatches.
- The corpus covered scalar, list, empty, `null`, undefined, numeric, boolean, spaced, mixed-case, nested, duplicate, frontmatter, and inline metadata tag shapes.
- Metadata-cache reads fell exactly from 200,000 to 100,000 across the randomized corpus and from 200,000 to 100,000 per 100,000-call benchmark round.
- In a representative one-frontmatter/one-inline-tag workload, median time fell from 35.650 ms to 34.568 ms (3.04%) and p95 fell from 36.656 ms to 35.255 ms (3.82%) across 41 interleaved rounds.
- A deliberately tag-heavy workload remained timing-neutral within noise while retaining the deterministic 50% metadata-read reduction.
- The relevant source and minified production bundle are each smaller; the bundle shrank from 228,688 to 228,643 bytes.

The benchmark isolates fallback note-tag comparison. Native Bases results, task parsing, card rendering, creation, drag/drop, settings, and persistence are unchanged.

## Validation

- Exact public `0.1.7` was pinned at commit `ef303c1dea76ea61bfa0e3d4ebf448af3877ee8b`.
- The untouched baseline passed all 77 declared checks, TypeScript, and its production build with runtime deployment suppressed.
- A focused baseline regression recorded the released two-read behavior and exact merged tag order.
- Final versioned `0.1.8` passed all 78 declared checks, TypeScript, the full declared test command, and a separate production-mode build.
- The final artifacts deployed byte-identically only to the registered Obsidian Plugin Test Vault.
- Obsidian 1.12.7 reloaded the isolated vault and rendered the existing `Plugin QA.base` Kanban view with the expected `todo 1` and `working 1` lanes and **Show completed** disabled.
- No card, task, checkbox, setting, or outbound action was invoked. Runtime-owned `data.json` and `.hotreload` remained byte-identical. Production was not accessed.

## Compatibility and limitations

- Minimum supported Obsidian version remains `1.10.0`.
- Note/tag filters, task filters, creation routing, hierarchy, drag/drop, commands, settings, stored data, and public integration behavior are unchanged.
- The supported GCM-first/native-standalone frontmatter route remains intact; removing it would remove standalone functionality and is outside this release.
- No settings or data migration is required.
